## Getting Started

First, clone the repository and enter its directory:

```bash
git clone https://github.com/gabe-hughesae5719/affinity-group-web-2026.git
cd REPO
```

The primary HTML file can be opened directly in a browser for local viewing. Alternatively, run a simple static server for a more reliable development setup.

For example, with Python:

```bash
python3 -m http.server 8000
```

Open the local address below after starting the server:

```text
http://localhost:8000
```
